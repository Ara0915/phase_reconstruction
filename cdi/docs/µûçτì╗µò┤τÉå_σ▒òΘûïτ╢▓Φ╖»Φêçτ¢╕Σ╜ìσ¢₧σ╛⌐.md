# 文獻整理：展開網路（algorithm unrolling）與相位回復的網路設計

> 2026-09-26 新增 §五：階段五（ptychography）的網路方向調查。

> 2026-09-24 整理，起因：4-2a 展開版（分段反傳）訓練後 +0.012，連內建的 50 輪 HIO 都沒用上（協定 §8.7、§8.8）。
> **注意**：以下多數依據摘要與二手摘要頁，未逐篇讀全文；標「未確認」者不可直接引用數字。

## 一、與我們最相關的原則

| 原則 | 出處 | 對應我們的問題 |
|---|---|---|
| **未訓練的展開網路應完全重現原演算法**（例：LISTA 由 ISTA 初始化） | Monga, Li, Eldar 2021（綜述） | 我們只讓中間的修正為 0；起點（偵測器端網路）與輸出頭都是隨機初始化 → 未訓練模型 ≠ HIO，保底不存在 |
| 展開的多半是**穩定的梯度型演算法**，學的是少量參數（步長、對角預條件） | UPR（Naimipour et al. 2020/2021）：SPARTA 20 層、IRWF 50 層，學對角預條件矩陣與量測矩陣 | 我們展開的是 HIO（混沌、非收縮），每 2 輪加一個自由的卷積修正 → 梯度不穩 |
| 固定點網路只對**最後一步**反傳（JFB），需要運算子是收縮的 | Fung et al.（JFB）；Gilton et al.（DEQ for inverse problems） | 與分段反傳同一思路的極端版；但 HIO 不收縮，直接套不成立 |
| 把網路**另外訓練**，再插進迭代演算法（plug-and-play），不對迭代反傳 | Işıl, Öktem et al. 2019；Deep PnP-HIO 2024 | 完全避開梯度爆炸；但網路變成 HIO 的輔助（使用者不希望），且很慢（PnP-HIO 約 200 外圈 × 5 次 HIO，每張約 4 分鐘） |

## 二、逐篇重點

**展開 / 迭代混合**
- **HIONet**（Digital Signal Processing, 2022）：把 HIO 展開成級聯網路，**以可學習的「先驗投影模組」取代 support 投影**（含空間與頻域殘差塊、attention），β 可學，各級共享權重，端到端監督訓練；起點為隨機或固定次數 HIO 的結果。與我們最接近的設計。（級數、訓練穩定性細節未確認）
- **UPR / Unfolded Algorithms for Deep Phase Retrieval**（Naimipour, Khobahi, Soltanalian）：展開 SPARTA（20 層）與 IRWF（50 層）；只學預條件矩陣（對角）與量測矩陣；Adam lr 1e-4；IRWF 展開版約 30 層即達原本 50 次的效果。訊號為一維高斯（非影像），應用情境與我們不同。
- **Deep Iterative Reconstruction for Phase Retrieval**（Işıl et al., Applied Optics 2019）：訓練 DNN 去除 HIO 的偽影，與 HIO 交替使用；另一網路做最後修飾。網路**分開訓練**。（交替次數未確認）
- **Deep Plug-and-Play HIO**（2024）：半二次分裂 + HIO 內圈 + 預訓練去雜訊器；比 HIO、prDeep、Iterative DNN-HIO 高約 1 dB，但每張約 247 秒。
- **prDeep**（Metzler et al., ICML 2018）：以去雜訊器作為正則化的相位回復（regularization-by-denoising）。

**訓練方式**
- **Deep Equilibrium Models**（Bai et al. 2019）、**DEQ for inverse problems**（Gilton et al. 2021）：迭代到固定點，用隱式微分訓練，記憶體與深度無關。
- **JFB**（Fung et al.）：只對最後一步反傳；需收縮運算子。

**CDI / ptychography 實務**
- **AutoPhaseNN**（Yao et al., npj Comput. Mater. 2022）：3D Bragg CDI；**物理前向模型放在 loss 裡**（比對估計與量測的繞射強度），不需真值；推論時只用 CNN，約比迭代法快 100 倍；CNN 輸出再接 ER 50 次，仍快約 10 倍且品質相當或更好。
- **PtychoNN / PtychoNN 2.0**（Cherukara et al. 2020；Babu et al., Nat. Commun. 2023）：**每個掃描位置一張繞射圖 → 網路輸出該處振幅 / 相位 → 拼接**；GPU 上 70 µs/張（14 kHz），邊緣裝置達偵測器 2 kHz；以迭代重建結果作訓練標籤、實驗中持續線上訓練；**無重疊時仍 > 90% 準確度**（迭代法 < 80%）。與階段五（ptychography）、最終目標（即時 4D-STEM）直接相關。
- **CNN 去雜訊降低 CDI 歧異性**（J. Synchrotron Rad. 2024）：對大量 HIO 重建做 Noise2Noise 去雜訊，把「不同起點間不一致的特徵」當雜訊；解析度 75 → 46 nm。

## 三、對我們的啟示（待診斷結果後討論）

1. **不論診斷結果如何，下一版展開網路都應先滿足「未訓練 = P-HIO」**：起點改為 HIO 的標準隨機起點（或讓偵測器端網路初始化為輸出 0 相位修正），輸出頭改為自然讀出 + 初始化為 0 的殘差。並以測試驗證**端到端輸出**，不只內部狀態。
2. 學的部分要小、要穩：參考 UPR / HIONet，只學步長、β、或取代投影的模組，而不是每輪加一個自由修正；或把 HIO 換成較穩定的步驟（ER、RAAR、梯度型）。
3. Plug-and-play 最穩，但網路成為輔助、且慢，與「網路為主」及「即時」的目標不符 → 不建議作為主線。
4. PtychoNN 的成功（逐位置、已知探針、拼接、即時）支持階段五的主線；其「無重疊仍準確」一點值得在報告中引用。
5. AutoPhaseNN 的「物理量測放進 loss」是另一種把物理嵌入網路的方式（不需真值、不需展開）；是否能解決 U-Net 學不會全域轉換的問題，文獻中沒有直接證據，需自己檢驗。

## 四、精讀補充（2026-09-24，讀方法段；HIONet 為出版社頁面摘錄，非全文）

### PtychoNN（Cherukara et al., APL 2020）與 PtychoNN 2.0（Babu et al., Nat. Commun. 2023）
| 項目 | 內容 |
|---|---|
| 架構 | 編碼器 + 解碼器（原版兩個解碼器：振幅、相位；2.0 只輸出相位，0.7M 參數，原版 4.7M） |
| 輸入 / 輸出 | 單一掃描位置的一張繞射圖 → 該處的**物體**（不是出射波）；2.0 輸入 128×128 |
| 探針 | **固定、已知的探針**；網路只針對該探針與一定範圍的折射率訓練 |
| 標籤 | **迭代重建的結果**（原版 ePIE 400 次；2.0 用 rPIE），不是真值 → 準確度上限 = 迭代法 |
| 資料量 | 原版 16,100 組（同一樣品前 100 條掃描線），約 800 組即可有合理結果；2.0 共 108,819 組 |
| loss | 逐像素 MAE；Adam |
| 拼接 | 各位置的輸出內插到規則網格後平均（以探針振幅加權，結果相近） |
| 測試 | 原版：同一樣品的最後 61 條掃描線（**同分布**）；2.0：不同重疊率 |
| 重疊 | 0.9 重疊時與迭代法幾乎相同；0.6 重疊時迭代法 SSIM < 80%、網路 > 90%；**0 重疊仍 > 90%**（相對於高重疊的迭代重建） |
| 速度 | 原版約 1 ms / 位置（比 Ptycholib 快約 300 倍）；2.0 在 RTX A6000 上 70 µs / 張（14 kHz）；邊緣裝置 100 Hz–2 kHz |
| 線上學習 | 實驗中持續用新的迭代重建結果增量訓練，部署到邊緣裝置 |
| 限制 | 超出訓練的折射率範圍要重訓；計數率 ±4 倍可容忍、±16 倍明顯變差；**訓練資料仍需高重疊掃描**；準確度受限於迭代法 |

**對我們的意義**
- 支持主軸：已知探針 + 逐位置網路 + 拼接 → 即時。與階段五、4D-STEM 目標同一形式。
- **公平比較的注意事項**：PtychoNN 的測試是同一樣品、同分布；我們 §四 看的是**未見分布**與非週期結構，標準更嚴。
  4-2a 的 U-Net（已知探針下 0.258、未見分布 1/4）與 PtychoNN 的成功並不矛盾，但報告中不能把兩者直接並列。
- 其「標籤來自迭代重建」的做法，與我們用模擬真值不同；實際儀器數據時可參考（無真值時的訓練來源）。

### AutoPhaseNN（Yao et al., npj Comput. Mater. 2022）
| 項目 | 內容 |
|---|---|
| 架構 | 3D 編碼器 + 兩個解碼器（振幅 sigmoid、相位 tanh）；輸入 64³ 繞射振幅 |
| 物理層 | 振幅、相位組成複數場 → FFT → 估計的繞射強度；support 由預測振幅 10% 門檻取得；zero padding 作為方框 support |
| loss | Σ\|√I_估 − √I_量\| / N³（繞射振幅的 MAE）；**全程不用真值** |
| 資料 | 模擬金晶體（fcc，4–20 個晶面，LAMMPS 加 ≤ 1% 應變）52,000 筆（旋轉擴增至 104k）；實驗前以 10 筆實驗數據擴增至 3,200 筆微調 |
| 精修 | 網路輸出作起點，ER 50 次；對照組為傳統 600 次（ER 20 / HIO 160 / ER 20 × 3，shrink-wrap） |
| 結果 | 網路單獨約快 100 倍；網路 + ER 50 次約快 10 倍，χ² 相當或更低；10 個實驗晶體與傳統重建一致 |
| 限制 | 只訓練在 fcc 金；理想散射模型；歧異性（翻轉、平移）**未討論**；未報告失敗案例 |

**對我們的意義**：「量測放進 loss」讓無真值的實驗數據可以訓練或微調；但它的成功也是**同類樣品**（金晶體），且仍接 ER 精修。
能否解決我們「網路學不會全域轉換、跨分布」的問題，文中沒有證據。

### HIONet（Digital Signal Processing, 2023；出版社頁面摘錄）
- 更新式：z^k = (1+β)x̃^k − x^{k−1}；x_r^k = z^k + T^k(z^k)；x^k = x_r^k − β x̃^k + x^{k−1}。
  對照 HIO：x^k = x^{k−1} − β x̃^k + P_S(z^k)。**HIONet 以學習的 z + T(z) 完全取代 support 投影 P_S**（我們 v3 是在 HIO 之後另加有界修正）。
- β 每級可學；起點為隨機或固定次數 HIO 的結果；loss = MSE + 0.1 × 邊緣 loss。
- **學習率 7e-5（MNIST / Fashion-MNIST）、2e-4（BSD）**，cosine 退火到 1e-6；訓練 64×64、測試 256×256。
- 級數、與 HIO / prDeep 的數字未能取得。

### PRISTA-Net（2023，coded diffraction patterns）
- 展開 ISTA（梯度型、穩定），**只有 7 級**；各級不共享權重較好；學步長、門檻、非線性轉換（含 Fourier 殘差塊、CBAM）。
- **多級 loss**：log(Σ_k L^k)（每一級都計 loss，取 log 放大小誤差時的梯度）。
- 量測是多張編碼遮罩的繞射圖（比我們的單張繞射容易）。

## 五、階段五（ptychography）的網路方向調查（2026-09-26）

> 目的：階段五若網路（5-3）沒有明顯改善，先準備好文獻支持的改良方向。
> **讀的深度**：PtychoPINN 讀了出版社全文的方法段；其餘為 arXiv HTML 全文或期刊頁面的方法摘要（經工具摘要，非逐字精讀）。**數字皆為各文自己的條件與指標，不可與我們的分數直接並列**。

### 5.1 一個共同的發現：成功的 ptychography 網路幾乎都不是「一張圖進、一塊出」

| 方法 | 網路輸入 | 物理怎麼用 | 訓練資料 | 報告的結果（各自條件） |
|---|---|---|---|---|
| **Friedrich et al.**（M&M 2023，Antwerp；4D-STEM 電子） | **相鄰 3×3 個位置的 CBED**（9 張） | 已知探針；相位物體近似；**從探針到輸出的全域殘差連接**；改良 U-Net | 742,688 筆模擬（Materials Project 12.6 萬個結構、multislice、30–300 kV、5–30 mrad、劑量 3–3e9） | 超解析（超過孔徑角）、抗雜訊；RTX 3080 上 75 萬個位置約 6 分鐘（> 2 kHz）；**限：需像差校正、已知低階像差、薄樣品** |
| **PtyRANNOSAUR**（arXiv 2026-06，UIUC；電子） | **5×5 個相鄰位置**（25 張）→ 中心位置的相位 | multislice、部分同調、多重散射；依電壓 / 厚度分三個模型 | **6,400 萬組**模擬（16,000 種材料，含空位、置換、扭轉） | 比 PtyRAD 快 60–100 倍；亞 Å 解析；**分布外時出現系統性誤差（對比下降、原子柱糊在一起）**，作者強調須以其他方法交叉驗證 |
| **PtychoFormer**（arXiv 2024；X 光） | **9 張相鄰重疊的繞射圖**依相對位置排成通道 | 已知探針；拼接 | 6.2 萬組 Flickr 影像 → 預訓練 24.5 萬筆 | 比 PtychoNN 振幅 / 相位 NRMSE 低 26% / 61%；重疊率僅 15% 仍可重建；零樣本換資料集可用；**網路 + ePIE（ePF）只少了約 100 次迭代**（ePIE 需 800–1500 次） |
| **PtychoPINN**（Sci. Rep. 2023，SLAC；X 光） | **4 張相鄰的繞射圖一組**，輸出各自的物體塊 | **物理放進網路與 loss**：各塊平移對齊後平均（重疊約束）→ 乘已知探針 → FFT → **Poisson 負對數似然**；**不需真值（非監督）** | 模擬（Lines、GRF、真實鎢樣品特徵），每種約 4.9 萬張 | 相對監督式 PtychoNN：PSNR 平均 +8 dB、線解析度約 4 倍；比 ePIE 快 100–1000 倍；**重疊掃描是必要條件**（用來打破中心對稱歧異） |
| **PtychoPINN-torch**（arXiv 2025-09，Towards generalizable…） | 同上 + CBAM | 同上；**用實驗量到的探針 × 程序生成的合成物體**（Dead Leaves、雜訊、procedural） | 2.8 萬張合成 | 一個模型處理 4 種探針、3 座光束線的未見實驗；比傳統 500 次快約 555 倍；**限：解析度與保真度仍不如迭代法**，作者定位為「實驗導引」而非取代定量重建；探針差太多即失效 |

→ **對我們的直接意義**：我原本規劃的 5-3 主角「逐位置 U-Net」是**一次看一張**；文獻中的成功例子幾乎都**一次看一整組相鄰、重疊的繞射圖**（3×3、5×5、9 張、4 張），讓網路自己利用重疊資訊。
Friedrich 與 PtyRANNOSAUR 的主體**仍是 U-Net 類的編碼器–解碼器**，只是輸入改為相鄰一組 —— 我們的 U-Net 可以沿用，改的是輸入。

### 5.2 解決「U-Net 學不會全域轉換」的架構做法（對應日誌 §十七）

| 做法 | 出處 | 對應 |
|---|---|---|
| 從輸入探針到輸出的**全域殘差連接**（網路只學樣品造成的改變） | Friedrich 2023 | 讓網路不必從零學轉換 |
| **Unit-modulus Fourier modulation（UFM）區塊**：在頻率空間做可學的相位調變、保持振幅；另有**全域傅立葉分支** | Lin, Tseng, Chen（NYCU）& Chen（**國網中心**），arXiv 2026-09，Zero-shot cross-material | 與我們 §17 的 fft 架構（把轉換內建進網路）同一思路 |
| 相位輸出改為 **(sin φ, cos φ)** 兩通道，避免 ±π 處不連續 | 同上 | 複數探針下 ψ 的相位會跨 ±π（4-2b 已遇到），網路輸出須處理 |

> 註：Zero-shot cross-material（2026-09）用**真實** 4D-STEM 資料（AuPd、MoS₂），以 ePIE 重建為標籤、**逐位置**（32×32 繞射圖 → 16×16 相位塊）＋高斯權重拼接；
> 跨材料零樣本 MS-SSIM 0.66–0.68（PtychoNN 0.53–0.56），比 ePIE 快約 10 倍（0.5 ms / 張）。作者含國網中心人員，與本專案使用同一個計算中心。

### 5.3 展開（unrolling）在 ptychography 的做法

- **PtychoDV**（arXiv 2023 → IEEE 2024）：**ViT 先給初始重建** → 展開 **Wirtinger Flow（梯度型、穩定）只 3 級**，每級接可學的卷積去雜訊；已知探針、Poisson 模型。
  稀疏掃描下 NRMSE 0.065（0.07 秒），與迭代法 PMACE 相同（35 秒），快 500 倍以上；純 CNN（PtychoNet）0.48、只用 ViT 0.44 → **展開的物理步驟貢獻很大**。
  限：純模擬；換成未見過的探針時 NRMSE 0.066 → 0.176；訓練約 120 小時。
- 與 4-2a 的對照：它展開的是**穩定的梯度法、只 3 級**，我們展開的是**混沌的 HIO、50 輪** —— 與 §四 的 UPR / PRISTA-Net 結論一致。

### 5.4 對階段五的建議（待寫入協定，須與指導教授確認）

1. **5-3 的主角改為「看相鄰一組繞射圖的 U-Net」**（例：3×3 = 9 張，對應 2×2 / 3×3 掃描），單張版保留為對照 —— 直接檢驗「網路能否利用重疊」。
2. **加一個「物理放進 loss」的變體**（PtychoPINN 式：重疊平均 → 乘已知探針 → FFT → Poisson 似然），和監督式同場比較；它不需要真值，也最接近實驗資料的情況。
3. 架構上可選擇加入**全域殘差 / 傅立葉分支**（Friedrich、UFM），針對 §十七 的轉換問題；相位輸出用 sin / cos。
4. 展開版若重開，採 **PtychoDV 式**：網路起點 + 少數級（≈ 3）的梯度型物理步驟，不再展開 HIO。
5. 「網路起點 + 迭代」的文獻結果也偏弱（PtychoFormer 的 ePF 只省約 100 次 / 800–1500 次），與我們的評估一致，維持為備案。
6. **訓練資料量的差距**要列為風險：文獻用 10⁵–10⁷ 筆（PtyRANNOSAUR 6,400 萬），我們目前 2 萬；若網路不如預期，資料量是必查的變因。
7. **泛化是所有方法公認的弱點**（PtyRANNOSAUR、PtychoPINN-torch、PtychoDV 皆明言）；我們堅持的「未見分布 + 同時間對手」評估比多數文獻嚴格，報告時應說明這點，而不是只跟文獻的數字比。
