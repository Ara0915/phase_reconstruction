# 期末考實驗設計協定

> **用途**：使用期末考資料之前，先固定陣容、資料、比較方式、判讀規則與檢查（同階段四至八的原則）。期末考資料**只用一次**，結果出來後不改任何規則。
> **版本**：v0.1 草案（2026-10-10，執行之前；待使用者確認）。
> **前情**：階段八結案（研究日誌 v15 §三十七、階段八協定 §二十）。優化方案 §九（9/27）：期末考 = 所有最終版本的網路，考**理想條件、貼近真實條件、晶格**三部分，用全新保留的資料，產生總結果表。
> **使用者的決定（10/10）**：(1) 晶格部分 P6B4e8-L、P6B4e8 都考；(2) 門檻：理想 / 貼近真實條件沿用 Q = 0.05 / 0.02（nerr_sr），晶格用 Q = 1.5 × CRLB；(3) 貼近真實條件的 13 個條件全考（重點是可重現性）；(4) 迭代法沿用 85 個設定，次數上限由 500 提高（目標 2000，先估時間）；(5) η 維持 0.1；(6) nerr 為主、SSIM 為副，三部分都算。
> **檔案**：只新增，放在 `claude_final/`；不修改既有檔案。

## 〇、要回答的問題

1. **可重現性**：驗證資料上得到的結論（階段六至八），在從未使用過的資料上是否成立？

## 三、對手：迭代法包絡

- **設定**：同階段七 / 八的 **85 個設定**（平常版 25 + 位置 / 探針修正版 60），在考試資料上整套重跑、重算包絡（同期中考）。
- **次數**：
  - 全部 85 個設定：0–500 次（停止點同階段七 / 八）；
  - **延長（事先選定的設定）**：每個條件 / 考卷，取**驗證資料上 500 次時誤差最低的 3 個設定**（從階段七 / 八已有的包絡檔決定，不看考試資料），延長到 **2000 次**（停止點 500 之後：700、1000、1400、2000）。
  - 理由：全部 85 個設定都跑到 2000 次約 4 倍計算量；500 次時最好的設定才是可能在之後越過門檻的設定。選法在看考試資料之前寫定；若延長的設定在 2000 次內仍未達到 → 報下界（= 2000 次的時間 / 網路時間）。
- **包絡** = 每個時間點下，所有（設定, 停止點）中 3 seeds 平均誤差最小者；在考試資料上挑選 → 對手偏樂觀（同前）。
- **計時**：最後的彙整 job、同一張 GPU；ms / 整張；batch 64 / 512；嚴格 fp32；其餘同階段七 §3.3（修正版的分段計時）。

## 五、比較方式

- **A、B**：Q = **0.05 / 0.02**（nerr_sr；**0.02 為主**，同階段七）；網路的 3 seeds 平均 ≤ Q → 達到；加速倍數 = 迭代法包絡最早達到 Q 的時間 / 網路的時間，以**區間**表示（同階段七）；**穩健加速** = 兩種 batch 的下界都 ≥ 1.25。
- **C**：**Q = k × CRLB**（雜訊極限；同 8c 的實作：Wei, Urbach & Coene 2020 的 Fisher 矩陣），**k = 1.5 為主判**（benchmark，使用者 10/10），k = 2 與「網路自己的品質」並列（使用者 10/10：三種都列）。
  - CRLB 在**考試資料的物體**上重算（前 192 個場，同 8c 的做法；各劑量以 1 / 劑量換算）。
  - 主判只在 **L-paper**（WS₂ / MoS₂ 另列）；L-combo、L-coh 的 CRLB 假設位置 / 探針已知（極限偏寬鬆 → 門檻偏嚴），**只作描述**；L-ideal、L-newdef（劑量 1）照算、描述（同 8c）。
  - **另報（描述）**：L-paper 的固定門檻 Q = 0.05 / 0.02（nerr_c；與階段八 h1 對照）。
- **晶格的任務版加速**（描述）：迭代法達到網路的 SV-F1 所需的時間 / 網路的時間（同階段八 h3）。

## 七、內建檢查（`--check`；全部通過才執行）

1. **重現**：在驗證資料上（各部分取 32 個場），網路與迭代法（每類設定各 1 個、20 次）重跑 = 階段七 / 八的結果檔（< 1e-5；GPU 上用相對容差，不要求逐位元）。
2. **條件的量測** = 階段七 / 八的產生方式（同 seed 時與既有程式的輸出一致）。
3. **seed**：考試資料的 seed 與所有既有腳本的常數、階段八的區間不重疊；`--check` 不產生考試資料（只驗證保護會拒絕）。
4. **CRLB**：沿用 8c 的 Fisher 恆等式核對（迷你問題）與零空間檢查。
5. **延長的設定**：選法只讀驗證資料的包絡檔；印出每個條件選到的 3 個設定並存檔（在考試之前固定）。
6. **凍結**：網路權重的 md5 = 階段七 / 八的模型檔。

## 十、限制（報告須註明）

- 全部為模擬資料；考試資料與驗證資料來自同一個產生器（可重現性 ≠ 對真實資料的泛化）。
- 迭代法包絡在考試資料上事後挑選（偏樂觀）；延長只對 3 個設定。
- 晶格部分的 benchmark 門檻 k = 1.5 是看過階段八結果後才選的（期末考之前寫定）；k = 2 並列。
- 其餘同階段七 §18.3、階段八 §十一、§二十（η、beamstop、高劑量的適用範圍等）。
