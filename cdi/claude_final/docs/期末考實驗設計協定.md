## 三、對手：迭代法包絡

- **設定**：同階段七 / 八的 **85 個設定**（平常版 25 + 位置 / 探針修正版 60），在考試資料上整套重跑、重算包絡（同期中考）。comboNP 只評估網路（同階段七 7c），沒有包絡。
- **次數 —— 以「時間上限」延長（v0.2，審查後改）**：
  - 時間上限 **T_H = AP-C 跑 2000 次的時間**，以階段八計時檔的每次時間算（b512：0.0182 ms × 2000 = **36.3 ms**；在考試之前固定）。
  - 每個設定的次數 n_s = 把 T_H / τ_s 取整，再夾在 **[500, 2000]**（τ_s = 該設定修正進行中的每次時間，b512，取自階段八的計時檔）→ 便宜的設定（AP 系列）延長到約 2000 次，昂貴的（ePIE 系列、修正中的版本）500 次就已超過 T_H、維持 500 次。
  - 停止點：0–500 同階段七 / 八，之後 700、1000、1400、2000（各設定到 n_s 為止，n_s 本身也是停止點）。延長的執行從頭跑（同一亂數流），前 500 次必須與只跑 500 次的結果相同（檢查）。晶格部分每個停止點也做 SV 判讀。
  - 理由：審查指出「只延長 3 個設定」時，其餘 82 個設定停在 500 次，包絡在更長的時間並不完整，「迭代法 2000 次內未達 → 下界」不成立。以時間上限延長後，**包絡在 T_c 以內完整**（T_c = 各設定最後一個停止點的時間的最小值，在彙整 job 重新計時後算出），迭代法在 T_c 內未達 → 下界 = T_c / 網路時間（不需要挑設定）。
  - 計算量約為只跑 500 次的 1.5 倍（以階段八的計時估算）。
- **包絡** = 每個時間點下，所有（設定, 停止點）中 3 seeds 平均誤差最小者；在考試資料上挑選 → 對手偏樂觀（同前）。
- **計時**：最後的彙整 job、同一張 GPU；ms / 整張；batch 64 / 512；嚴格 fp32；其餘同階段七 §3.3（修正版的分段計時）。
- 另報迭代法的發散率（各設定、各停止點；描述）。

## 五、比較方式

- **A、B**：Q = **0.05 / 0.02**（nerr_sr；**0.02 為主**，同階段七）；網路的 3 seeds 平均 ≤ Q → 達到；加速倍數 = 迭代法包絡最早達到 Q 的時間 / 網路的時間，以**區間**表示（同階段七）；迭代法在 T_c 內未達 → 下界 T_c / 網路時間；**穩健加速** = 兩種 batch 的下界都 ≥ 1.25。
  - 另報（描述，不是刀口上的判斷）：**以網路自己的品質為門檻**的加速倍數（同 8c D 項）、網路 vs 同時間包絡的誤差比值與 z（同階段七 / 期中考）。
  - cohL / cohH：迭代法沒有混合態修正 → 加速只作描述（同 7b）；posX / prbX 超出訓練範圍（註明）。
- **C**：**Q = k × CRLB**（雜訊極限；同 8c 的實作：Wei, Urbach & Coene 2020 的 Fisher 矩陣），**k = 1.5 為主判**（benchmark，使用者 10/10），k = 2 與「網路自己的品質」並列（使用者 10/10：三種都列）。
  - CRLB 在**考試資料的全部 512 個物體**上重算（與 nerr_c 平均的場相同；8c 的做法，約 10 分鐘；各劑量以 1 / 劑量換算）。CRLB 只依物體與量測模型，與任何結果無關。
  - **加速倍數 vs k 的曲線**（描述）：k = 1.25、1.5、1.75、2、2.5、3 → 呈現門檻選擇對結論的影響（k = 2 時迭代法較快、k = 1.5 時網路較快，階段八的觀察）。
  - 主判只在 **L-paper**（WS₂ / MoS₂ 另列）；L-combo、L-coh 的 CRLB 假設位置 / 探針已知（極限偏寬鬆 → 門檻偏嚴），**只作描述**；L-ideal、L-newdef（劑量 1）照算、描述（同 8c）。
  - **另報（描述）**：L-paper 的固定門檻 Q = 0.05 / 0.02（nerr_c；與階段八 h1 對照）。
- **晶格的任務版加速**（描述）：迭代法達到網路的 SV-F1 所需的時間 / 網路的時間（同階段八 h3）。

## 七、內建檢查（`--check`；全部通過才執行）

1. **重現**：在驗證資料上（各部分取 32 個場），網路與迭代法（每類設定各 1 個、20 次）重跑 = 階段七 / 八的結果檔（< 1e-5；GPU 上用相對容差，不要求逐位元）。
2. **替換 seed 基底後的路徑**：以驗證資料的基底跑新腳本的路徑 = `a7.setup_cond` / `s8.setup_exam`（量測、位置、離焦、物體完全相同）。
3. **seed**：考試資料的 seed（含派生的 + 1000 × s、+ 1、+ 1000 × i 等）與所有既有腳本的常數、訓練池（50M + 10M × s + 10k × k）、階段八的區間不重疊；`--check` 不產生考試資料（只驗證保護會拒絕；物體雜湊的比對在 `--run` 開始時做）。
4′. **延長的一致性**：同一設定跑 n_s 次時，前 500 次的停止點 = 只跑 500 次的結果（迷你問題）。
4. **CRLB**：沿用 8c 的 Fisher 恆等式核對（迷你問題）與零空間檢查。
5. **延長的次數**：每個設定的 n_s 由階段八的計時檔算出，印出並存檔（考試之前固定）。
6. **凍結**：網路權重的 md5 = 階段七 / 八的模型檔。
