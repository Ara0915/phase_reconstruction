## 4. 參考文獻與輔助資訊（接手後用到的）

- **Chen et al. 2024**, *Sci. Rep.* 14, 277：200 kV 電子疊層成像觀察單層 MoS₂ / WS₂ 單原子缺陷（指導教授提供；階段八對齊的論文；重建無實體 beamstop、2 個混合態模式）。

- **Jiang et al. 2018**, *Nature* 559, 343（arXiv 1801.04630，使用者提供）：80 keV 單層 MoS₂ 疊層成像；arXiv 版只呈現相位，無法換算 η。

## 6. 程式怎麼送到國網、結果怎麼拿回來（階段八、8c、8d 的實際流程）

國網不直接接 GitHub。流程是：**Claude 推到 GitHub → 使用者在自己電腦 git pull → scp 上國網 → 在國網安裝與執行 → 結果 scp 回電腦 → commit / push → Claude 判讀**。

**① 使用者電腦（PowerShell，在 repo 根目錄）：更新**
```
git pull origin claude/response-check-lqqirh
```

**② 使用者電腦：只上傳這次的 `*_update` 資料夾**（國網上既有的檔案不會被動到）
```
scp -r cdi/claude_stage8/scan8d_update elviss0915@nano5.nchc.org.tw:~/cdi/
```
- 會要求密碼與 IDExpert 的 OTP（同平常 ssh）。若連不上，先前用過 `scp -P 2222 ...`（**大寫 P**；小寫 -p 是別的意思）。

**③ 國網登入節點：安裝（只複製檔案、不計算）**
```
cd ~/cdi
sed -i 's/\r$//' scan8d_update/*        # Windows 換行（安裝腳本也會處理）
bash scan8d_update/install_scan8d.sh
```
- 安裝腳本比對依賴檔的 md5、**不覆蓋內容不同的既有檔案**（要換新版時先刪掉舊的新增檔，例：8c v1 → v2 時 `rm ~/cdi/scan_8c.py`）；最後印出 md5，與 Claude 給的值核對。

**④ 國網 dev 計算節點（不可在登入節點計算）**：`python scan_8d.py --check` → `python scan_8d.py --smoke`（通過會寫 PASSED）→ 輸出貼給 Claude。

**⑤ 正式送件**：`sbatch run_scan8d.sh`（`-A mst114378 -p normal2`，帳號同時最多 2 個 job）；log 在 `/work/elviss0915/runs/logs/<job名>_<jobid>.out`，結果在 `/work/elviss0915/runs/`，圖在 `~/cdi/figs_*/`。

**⑥ 結果拿回來**：在國網把 log、json、圖集中到一個資料夾，scp 回電腦的 repo（例：`cdi/claude_stage8/results_8d/`），然後
```

git commit -m "stage 8d results from NCHC"
git push origin claude/response-check-lqqirh
```
再告訴 Claude「推上去了」，Claude `git pull` 後讀完整輸出判讀。
