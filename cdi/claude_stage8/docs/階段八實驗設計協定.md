## 二、晶格產生器

### 2.1 幾何

| 項目 | 設定 | 依據 |
|---|---|---|
| 結構 | 單層 TMD（1H，三角柱配位）沿 [001] 投影：蜂巢狀，金屬柱與 S₂ 柱（上下兩個 S 疊在同一位置）交錯。以晶胞向量與原子的分率座標建構（不以最近鄰距離當晶格常數） | 論文樣品 |
| 晶格常數 | a = 3.16 Å（MoS₂）/ 3.15 Å（WS₂）；以 Δx = 0.358 Å/px 換算 ≈ **8.83 / 8.80 px**；金屬–S₂ 投影距離 a/√3 ≈ 5.10 / 5.08 px | 階段七 §十二 的尺度 |
| 材料 | 每個場 MoS₂ 或 WS₂（整個場同一種材料）；**驗證場固定 256 / 256**（分層），訓練場隨機各半 | 論文兩種都有 |
| 旋轉 | **U(0°, 120°)**（v1.1：金屬與 S₂ 是不同的子晶格，對稱只有三重） | 不讓網路背方向 |
| 平移 | 整個晶格在一個晶胞內均勻隨機 | 不讓網路背格點位置 |
| 應變 | 對稱應變張量 ε_xx、ε_yy、ε_xy 各 U(−0.02, 0.02) | 小幅、真實樣品常見 |
| 熱振動 | **只用平均位勢 + Debye–Waller 模糊**（v1.1：不再另加隨機原子位移，避免重複計入）；u_rms = 0.05 Å（Mo、W）/ 0.07 Å（S），屬假設的量級 | 審查意見 |
| 範圍 | 產生時加 halo（每邊多 16 px）再裁成場的大小，避免邊界與 FFT 週期捲繞；訓練用的小場同一產生器 | — |

### 2.2 原子的相位與振幅（以 abTEM 校準）

- **相位**：φ(r) = σ · V_proj(r)，σ（200 kV）= 7.288 × 10⁻⁴ rad/(V·Å)；V_proj 為 Kirkland 參數化的投影位勢，乘上 Debye–Waller 因子 exp(−2π²u²k²)。
- **取樣方式（v1.1 明定）**：模擬網格上的相位 = 把連續位勢**限制在網格的頻帶內（方形 Nyquist，k ≤ 1/(2Δx) = 1.397 Å⁻¹）再取樣**。實作：在頻率空間對每個原子乘上散射因子（含 Debye–Waller）與次像素平移的相位，再逆 FFT（這也自然處理次像素位置）。
  - 由 Claude 在雲端工作區以 abTEM 的 Kirkland 係數產生每種元素的徑向散射因子表（1D，k 的格點），寫進 `scan_8.py` 當常數 → 國網不需要安裝新套件。
  - 審查估計的峰值（孤立柱、在格點中心）：Mo 約 0.59 rad、W 約 0.84 rad、S₂ 約 0.55 rad（頻帶限制）；約為 π/2 的 32–54% → **不是「遠小於 π/2」**（v1.0 的說法更正）。
  - **相位範圍**：P6B4 系列的投影把相位截在 [0, π/2]。所有驗證與訓練場的最大相位必須 < π/2；任何場超過 → 停止、回報（不縮放，避免脫離物理）。另外記錄次像素位置對峰值的影響（同一原子在 0 / 0.5 px 偏移時的峰值）。
  - 頻帶限制會在原子周圍產生小的負振鈴；相位截在 [0, π/2] 會截掉負值 → `--check` 記錄負相位像素的比例與最小值（描述；若 < −0.05 rad 的像素 > 1%，回報並與使用者討論）。
- **振幅**：a(r) = exp(−η · φ(r))，**η = 0.1**（現象學的弱吸收假設，不是通用值；局部強度損失約 10–16%）。真空 a = 1。
  - 敏感度（描述，v1.1）：8a 另在 128 個 L-ideal 場上用 η = 0 重測凍結的網路與 P6B4e8-L（只網路）。
- 真空的相位 = 0（與現有物體的慣例相同：相位在 [0, φ_max]）。
- **與現有訓練物體的差別**（照實記下）：程序生成物體的背景振幅為 0、物體內平均振幅約 0.4；TMD 幾乎是純相位物體，振幅約 1。這是很大的分布差異，是 8a 要量的東西。

### 2.3 缺陷

| 缺陷 | 投影後的樣子 | 產生方式 | 用途 |
|---|---|---|---|
| S 單空缺（SV） | S₂ 柱少一個 S → 相位約一半 | 每個 S 原子以機率 p_SV 移除；每個場 p_SV ~ U(0, 0.03) | **訓練 + 測試** |
| S 雙空缺（DV） | S₂ 柱兩個 S 都不見 → 該點只剩真空 | 每個 S₂ 柱以機率 p_DV 整柱移除；每個場 p_DV ~ U(0, **0.02**)（v1.1：由 0.01 提高，增加 DV 樣本） | **訓練 + 測試** |
| 線缺陷（LD） | 一排 S 空缺連成線 | 沿三個晶格方向之一，長 5–15 個 S₂ 位置；每個位置隨機少一個或兩個 S；每個場 1–3 條；至少 5 個位置落在 U 內 | **只測試** |
| 缺 S 區域（MR） | 一小塊區域只剩金屬 | 圓形區域、半徑 4–8 Å 內所有 S 移除；每個場 1 塊；中心在 U 內 | **只測試** |

- 優先順序（重疊時）：缺 S 區域 > 線缺陷 > DV > SV（同一柱只套最高者）。
- 雙空缺在論文中也可能指「相鄰兩個位置各少一個 S」；本協定用「同一柱兩個都不見」（註明）。
- **數量（v1.1 更正）**：U 內約 47 個 S₂ 柱 × 512 個場 ≈ 24,000 柱；預期 SV 約 700、DV 約 250（材料分組後各一半）。缺陷在同一場內聚集、3 個 seed 共用真值 → 統計以「場」為單位（§4.4）。

### 3.4 劑量校準（v1.1：以「每張繞射圖的入射電子數」對齊論文）

- **入射電子數**：N_inc = photons_per_pix × W² / ref_energy × Σ|P|²（正交 FFT；完全透明的物體、beamstop 之前的總計數期望），以量測實際使用的 cfg（`scan_cfg` 之後的 ref_energy）直接算出；Poisson 抽樣的總數只作驗證。
- **對齊目標 = 論文每張的入射電子數**（網路看到的是每張的雜訊）：
  - WS₂：1.27 × 10⁴ × 3² = **1.143 × 10⁵** → 劑量比 f_W = 1.143 × 10⁵ / N_inc；
  - MoS₂：4.48 × 10⁵ × 0.6² = **1.613 × 10⁵** → f_Mo = 1.613 × 10⁵ / N_inc。
  - 兩種材料每張的電子數接近；但我們的步距較大 → **每單位面積的劑量**：WS₂ 約為論文的 1.1 倍，MoS₂ 約為論文的 1/23（照實註明）。
- `--check` 印出 N_inc、f_W、f_Mo 並存檔；正式評估讀回、不重算。
- **檢查分三種（v1.1）**：(1) 透明物體的平均總計數 / N_inc = 1 ± 1%；(2) 實際 TMD 場的平均偵測計數（含 |O|² 與 beamstop）另外列出；(3) L-paper 的平均偵測計數 / 期望 = 1 ± 2%。不把 TMD 的偵測計數直接當入射數比。
- **訓練範圍的核對**：訓練的劑量比範圍為 [0.01, 1]（同 7d）。若 f_W 或 f_Mo < 0.01 → 8b（L 與 C 兩組）的**晶格樣本**劑量下限改為 min(f_W, f_Mo) / 2，原本資料的樣本維持 [0.01, 1]（事先寫定），並在結果中註明 8a 的該材料是「超出訓練範圍」。f > 1 不會發生（論文的電子數遠低於基準）；萬一發生 → 停止、回報。
- **附帶更正（待數字確認）**：階段七 §十二 把基準劑量換算為約 4.8 × 10⁵ e/Å²，用的是程序生成物體的平均偵測計數（暗背景會吸收一部分）。以入射電子數算會更高；「doseL / doseH 涵蓋論文範圍」的說法**要依 N_inc 重算後才能下結論**，在階段八的結果中更正。

### 4.3 指標

**(a) 為什麼晶格不能直接用 nerr_sr 的門檻（重要）**

- nerr_sr = Σ_U |估計 − 真值|² / Σ_U |真值|²。程序生成物體的背景振幅為 0 → 輸出全黑的 nerr ≈ 1，門檻 0.02 有意義。
- TMD 的振幅約 1、相位對比小 → Σ|真值|² 主要是均勻的背景。**一張沒有結構的平面就可能得到很小的 nerr_sr**。直接套 0.05 / 0.02 會讓空白影像「過門檻」。
- 因此晶格的主指標改為**對比正規化誤差** nerr_c：

| 指標 | 定義 | 用途 |
|---|---|---|
| **nerr_c（晶格的主指標）** | 對齊同 nerr_sr（整體相位 + 平移 + 相位斜坡；同一組對齊參數 —— 分母固定，最小化的目標與 nerr_sr 相同，不會新增偏差），nerr_c = Σ_U \|估計 − 真值\|² / Σ_U \|真值 − c*\|²，c* = mean_U(真值)（複數平均） | **最佳複數常數 c* 的 nerr_c = 1**（與程序生成物體「全黑 = 1」的意義相同）；門檻沿用 **Q = 0.05 / 0.02 / 0.01（主 0.02）**。另報「振幅 1、相位常數的平面」的 nerr_c（約 1，描述） |
| nerr_sr | 同階段七 | 與階段七連續 |
| 相位 RMS（mrad）、振幅 RMS | 對齊後、U 內逐像素 | 依品質門檻文獻整理的建議分開報告 |
| SSIM（副） | 同 7b（振幅、相位分開；相位的遮罩改為全部像素，因為振幅處處約 1） | 排名一致性 |
| **FRC**（描述） | 對齊後、U 內接的 48 × 48 方塊、Tukey 窗（α = 0.25）；先減去平均；環寬 1 個頻率格點；**pooled FRC = 512 個場合併的互譜實部 / √(兩邊合併功率的乘積)**；功率 < 總功率 10⁻⁶ 的環記為不可定義；MoS₂ / WS₂ 分開 | 誤差按頻率拆開看（使用者 10/6 同意，只當描述）。晶格的功率集中在布拉格峰，曲線在峰之間可能先掉再回升 → **只報整條曲線與在各布拉格反射處的值**，不把第一次越過 0.5 稱為解析度；圖上標出各反射與取樣極限（0.72 Å，Nyquist） |
| **空缺判讀**（任務指標） | 見 (b) | 論文的主題 |
| 資料一致性殘差（描述） | 估計物體重新算出的繞射振幅 vs 量測（beamstop 外），各方法同一程式 | 輔助判斷「補回」是否違背資料（§六 h8） |

**(b) 空缺判讀的定義（自訂；論文為目視，報告時註明）**

1. 用**完整的對齊結果**（整體相位 + 平移 + 相位斜坡）。
2. 在每個**真值的** S₂ 位置（取樣圓須完整落在 U 內）取半徑 1.5 px 圓內的平均相位，減去鄰近 3 個空心位置（六角晶格中心）的平均相位 → 柱的訊號 s。
3. **正規化不用真值標籤（v1.1）**：以該場**所有** S₂ 柱的 s 中位數 m 正規化（空缺比例 ≤ 約 5%，中位數代表完整柱）→ ρ = s / m。
4. **無效規則（v1.1）**：若 m ≤ 真值場的對應中位數 × 0.25（重建的 S₂ 對比太弱或為負）→ 該場判為「無法判讀」，所有柱計為**判錯**（SV / DV 記為漏掉、完整柱記為誤報）。報告無法判讀的場的比例。
5. 分類：ρ ≥ 0.75 → 完整；0.25 ≤ ρ < 0.75 → SV；ρ < 0.25 → DV（門檻 = 理想值 1、0.5、0 的中點；事先寫定）。
6. 報告：
   - **3 × 3 混淆矩陣**（完整 / SV / DV）；
   - **SV 專屬的精確率、召回率與 F1（主判讀用，h3）**；DV 同樣；
   - 「有空缺 vs 完整」的二元 F1（輔助；SV 全被判成 DV 時二元 F1 仍可能很高，所以不當主判讀）；
   - 誤報率（完整柱被判成空缺）；
   - **補回率**：真值有空缺（SV 或 DV）卻被判成完整的比例。分母 = U 內的真值空缺柱數；分母為 0 的場不計入。
   - 另報對比增益（描述）：重建的 m / 真值的 m（看重建是否整體壓低了對比）。
- 位置用真值 → 這是評估「影像上看不看得出來」，不是自動找原子的演算法（註明）。空心位置含鄰原子的尾巴，兩邊（網路、迭代法）一致；更精細的柱強度擬合列為之後的工作。
- 迭代法：在每個停止點都算（計算便宜，放進包絡的量測迴圈）→ 可得到「迭代法達到同樣 SV-F1 的最短時間」。

**(c) 失敗值（v1.1）**：估計發散（NaN / inf）的樣本：nerr_sr 同階段七記為 4.0；**nerr_c 記為 max(10, 該條件所有方法中最大有限值 × 1.5)**（確保發散不會比任何有限結果好）；空缺判讀記為「無法判讀」。另報每個方法的失敗率。

### 4.4 比較方式與統計

- **加速**：同階段七：網路的 3 seeds 平均 ≤ Q → 達到；加速倍數 = 迭代法包絡最早達到 Q 的時間 / 網路的時間，以**區間**表示（下界用前一個停止點）；**穩健加速 = b64 與 b512 的下界都 ≥ 1.25**。指標換成 nerr_c。
- **任務版的加速**：迭代法包絡（以 SV-F1 取最好的設定）達到「網路的 SV-F1」與「SV-F1 = 0.9」所需的時間 / 網路的時間（同樣以區間表示）。
- **特殊情況（事先寫定）**：
  - 網路達不到 Q → 記「網路未達」；迭代法 500 次內都達不到 → 記「迭代法未達」；兩者都未達 → 列出各自的最佳值。
  - 迭代法在 0 次（起點本身）就達到 → 加速倍數 = 迭代法起點的時間 / 網路時間（照算，註明）。
  - 某個 seed 的網路失敗 → 3 seeds 平均照用失敗值，另列各 seed。
- **網路之間的比較（同階段七的寫法，v1.1 明定）**：比值 = 3 個 seed 的逐 seed 比值的**幾何平均**；z 與「≤ 0.8 且 z < −2 / ≥ 1.25 且 z > 2」的規則同階段七（`scan_5b.ratio`）。
  - 註明：只有 3 個 seed，|z| > 2 是本研究一貫使用的**經驗判準**，不是嚴格的顯著性檢定（自由度 2）。
  - 另報**以場為單位的成對 bootstrap 95% 區間**（重抽 512 個場，每個場整場帶著它的所有柱；2000 次），不把原子柱當獨立樣本。
- **主假說只有 (h1)**；其他判讀為次要或探索性（多重比較不另校正，註明）。

## 十一、限制（報告須註明）

1. MoS₂ 的掃描（步距 2.86 Å vs 論文 0.6 Å）：重疊少很多、每單位面積的劑量低約 23 倍（每張電子數對齊）。
2. 離焦約 14 nm（論文 20 nm）；收集角 35 mrad（論文 116 mrad）、偵測器 64 × 64；我們有 beamstop、論文的重建沒有。
3. 原子為 Kirkland 投影位勢的頻帶限制取樣（單層、弱相位近似、無多重散射）；熱振動以 Debye–Waller 處理（u 為假設量級）；吸收 η = 0.1 為現象學假設（另做 η = 0 敏感度）。
4. 我們的迭代法沒有混合態修正（L-coh 對迭代法偏不利）。
5. 空缺判讀為自訂的定義（論文為目視），且使用真值的位置。
6. 論文只有實驗資料 → 我們只能對齊條件，不能直接和論文的影像比數字。
7. 3 個 seed 的 z 為經驗判準；以場為單位的 bootstrap 為補充。
8. 全部為模擬資料；期末考的晶格部分（seed 98,000,000 系列）作最終確認。

## 十三、使用者的決定（v1.2–v1.5，2026-10-06）

### 13.1 劑量：維持 v1.1 的標準

- 兩種材料都對齊**論文每張繞射圖的入射電子數**（§3.4），不另外加「MoS₂ 對齊每平方埃」的考卷。
- 背景（Claude 的說明）：步距不同，兩種劑量不能同時對齊；對齊每平方埃時 MoS₂ 的劑量比估計約 0.4–0.6，而階段七中劑量 ÷ 10 幾乎沒有影響 → 預期與 L-ideal 的 MoS₂ 組相近（描述；報告時可引用 L-ideal 的 MoS₂ 組說明）。

### 13.2 晶格訓練池：維持固定的 10 萬個場，看 8b 的結果再判斷（v1.4 定案）

- **決定（使用者 10/6，v1.4）**：8b 照 §五 執行 —— 晶格池固定 10 萬個場（v1.5 起每個場在 20 個 epoch 中平均約看 10 次；誤差與雜訊每步重抽），**不預先排除過擬合**。
- 理由（使用者）：
  1. 想先確定過擬合是否存在；一開始就用「每步現場產生」會把它排除掉，等於跳過這個問題；
  2. 若 8b 學得不錯或落差比合理，預先排除是多餘的；
  3. 先前的訓練都用固定的資料池，維持一致性；
  4. 想看到真正差的結果，再去找可能的原因。
- 過程紀錄：v1.2 依使用者的說法寫成「看 8b 的結果」；v1.3 一度誤解為「依 8a 決定」（8a 沒有訓練，看不出過擬合，只能當風險的間接預估）；使用者比較三種做法（依 8a、看 8b、一開始就現場產生）後選擇看 8b，v1.4 定案。v1.3 的「8a 預檢」取消。
- **之後的判斷規則（事先寫下）**：若 8b 的結果不理想 —— (h1) 未達 Q = 0.05，或 (h5) 的 P6B4e8-L vs P6B4e8 未達「改善」—— 先看 (h12) 的落差比：
  - 晶格的落差比 ≥ P6B4e8 在原本資料上的落差比的 **1.5 倍** → 過擬合是可能的原因，下一版微調把它納入調整的因素（例如晶格場改成每步現場產生、增加晶格池、減少 epoch）；
  - 否則 → 過擬合不是主因，另找原因（分布差異、劑量、訓練步數等）。
  - 任何後續的微調都另寫版本、與使用者確認後才做；新的結果另外標示，不覆蓋本版的結果。

### 13.3 8b 的訓練步數：與 P6B4e8 相同（v1.5）

- **決定（使用者 10/6）**：P6B4e8-L 與 P6B4e8-C 都改為 **20 epochs × 每個 epoch 10 萬個樣本 ≈ 15,620 步**，與 7d 的 P6B4e8 相同（v1.1 為一半，約 7,810 步）。
- 理由：
  - 「一半」是依微調慣例的判斷，沒有數據根據；
  - 與之前的訓練預算一致；
  - 結果不理想時可以排除「步數不足」，比較好診斷（使用者）。
- 影響：
  - 每個晶格場與原本的場平均各被看到約 10 次 → 過擬合較可能出現（使用者本來就想確認它是否存在，§13.2 的落差比規則照用）；
  - 忘記舊能力的風險稍高 → (h6) 與對照組 C 會抓到；
  - 每個訓練約 65–75 分鐘，整體多約 1.5 小時。
